# E-Ticketing Monorepo

Production-ready monorepo for a FlixBus-like e-ticketing platform.

- Frontend: Angular 17, Angular Material, TailwindCSS, NgRx, SSR, i18n
- Backend: Spring Boot 3.3 (Java 21), MongoDB, Spring Security, OpenAPI
- Infra: Docker, docker-compose, Kubernetes manifests, GitHub Actions CI

See README.md for setup. This document will evolve as modules are added.
